# Дизайнер презентаций — правила для агента

Локальное веб-приложение для презентаций по корпоративным гайдлайнам. Приложение хранит проекты, гайдлайны, комментарии и экспорт. Агент (ты) собирает гайдлайны, создаёт презентации и применяет правки к HTML-слайдам. Документация: `docs/INDEX.md`.

## Процедуры
| Запрос | Процедура |
|---|---|
| `/process-edits`, `/presentations правки`, «обработай правки» | `.claude/commands/process-edits.md` |
| `/presentations создать`, «создай презентацию из приложения» | `.claude/commands/create-presentation.md` |
| `/presentations гайд`, «собери гайдлайн» | `.claude/commands/build-guide.md` |

Состояние заявок (`request.json`, `lifecycle.json`) и интервью — только через `agent.py task-*`. Вопросы пользователю — строго по одному.

## Правки из приложения
- Когда пользователь пишет `/process-edits`, «обработай правки» или похожее, выполняй `.claude/commands/process-edits.md`.
- Состояние заданий меняется только через `python3 app/tools/agent.py`. Файлы `Проекты/*/edits/*.json`, `*.lock`, `.state/` руками не трогать.
- Правишь только HTML и `styles.css` внутри `Проекты/<проект>/`. Не трогай `project.json` (порядок и скрытие слайдов задаёт приложение; список слайдов при генерации — `agent.py sync-slides`), `history/`, `Экспорт/`. `Гайдлайны/` меняешь только при сборке гайда.
- Не нашёл выделенный текст однозначно, значит ставь `needs_input`. Похожий фрагмент вместо него не правь.

## Слайды
- Каждый слайд — отдельный HTML 1920x1080 с `<div class="slide">`, стили из `../styles.css`, ресурсы из `../assets/`.
- Без `<script>` и внешних URL: в превью скрипты запрещены (CSP), экспорт идёт офлайн.
- Оформление по гайду проекта: `Гайдлайны/<guideline_set_id>/` — `guide.md`, `guide.json`, эталоны `examples/`. Цвет текста — только классами гайда.
- Цифры и факты — только из исходников и ответов пользователя.
- После изменений слайдов — `python3 app/tools/check_slides.py <проект>` (контраст, пустой низ, переполнение, мелкий текст).

## Код
- Python только stdlib, совместимость с 3.9: тесты гонять через `/usr/bin/python3`. Никаких pip-зависимостей.
- JSON пишется атомарно через `app/core/store.py` (`write_json`).
