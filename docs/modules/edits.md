# Правки

## Цикл
1. Черновик в UI: комментарий к слайду или к выделенному фрагменту (хранится в localStorage по `slide_id`, пока не сохранён).
2. «Отправить агенту» → `POST .../edits` → `edits-vN.json` (HTML не меняется).
3. UI: «Задание vN ждёт агента» + копирование `/presentations правки`.
4. Агент обрабатывает по контракту → `docs/architecture/agent-contract.md`.
5. UI показывает статус итерации и результат каждой правки с комментарием агента.
6. «Откатить слайд» в карточке задания → `POST .../edits/{n}/slides/{slide_id}/revert {revert:true}`; «Вернуть правки слайда» — `{revert:false}`. Откат только на уровне слайда внутри задания, отдельной правки нет.

## Откат слайда (`store.set_slide_reverted`)
- Откатывает все правки слайда из задания vN: от последней к первой; возврат — в прямом порядке. Состояние хранится по каждой правке.
- Хунки строятся difflib по строкам, с одной строкой контекста с каждой стороны.
- Откат: в текущем файле фрагмент «стало» → «было»; возврат — наоборот. Поздние правки в других местах не затрагиваются.
- Фрагмент не найден или найден больше одного раза → конфликт (RuntimeError, 409), файлы не меняются: все хунки всех правок слайда применяются вместе или ни один.
- Хунк на весь файл — только если файл с тех пор не менялся.
- Запрещено, пока итерация не завершена или агент работает над любой итерацией проекта.
- Правки без снимка (`begin` не вызывался) — без кнопки отката.

## Валидация при создании (`store.create_edits`)
- Непустой список, непустой комментарий (до 4000 символов).
- `slide_id` существует (для `scope: slide`).
- selection без текста → обычный комментарий.

## Поиск выделения (`app/core/textmatch.py`)
- Сравнение по видимому тексту без пробельных символов: NBSP, переносы между блоками, мягкие переносы, zero-width не влияют; сущности (`&nbsp;`) раскрываются.
- Текст в `<style>`, `<script>`, `<title>`, `<head>` игнорируется.
- Несколько совпадений → фильтр по prefix/suffix.
- Результат — точный кусок сырого HTML (`raw`), можно через несколько тегов.

## Тесты
`app/tests/test_agent_cycle.py` (11): уникальность версий, двойной захват, begin обязателен, NBSP, неоднозначность, prefix, зависший агент и takeover, падение посреди правки без ложного «Готово», откат слайда без затирания правок других заданий + возврат, конфликт отката, запрет отката в работе, path traversal, атомарная запись.
