# Дизайн интерфейса

Файлы: `app/static/index.html`, `app/static/app.css`, `app/static/app.js`, шрифт `app/static/fonts/` (Inter, OFL, без CDN).

## Принципы (решения автора)
- Минимализм в духе macOS: стекло на панелях, мягкие тени, системные отступы.
- Только светлая тема. Акцент — синий `#0077FF`. Язык — русский, без терминов.
- Статусы — иконка + текст, не только цвет. `prefers-reduced-motion` отключает анимации.

## Токены (`:root` в app.css)
| Токен | Значение |
|---|---|
| --accent / --accent-hover / --accent-soft | #0077FF / #0068E0 / 10% |
| --text / --text-2 / --text-3 | #1D1D1F / #6E6E73 / #8E8E93 |
| --canvas / --bg / --sidebar | #F5F5F7 / #FFF / rgba(242,242,245,.82) + blur |
| --green / --orange / --red | #28A745 / #E08600 / #E5352B |
| радиусы | 8 / 12 / 18 |
| --spring | cubic-bezier(.32,.72,0,1) — появления, sheet, сегменты |
| шрифт | Inter 13px, fallback -apple-system |

## Раскладка (grid)
`тулбар 52px` сверху; колонки: `сайдбар 228` (проекты, правила) · `навигатор 196` (миниатюры) · `сцена` (превью 16:9 + поле комментария) · `инспектор 320` (сегменты «Комментарии» / «Задания»). При ширине < 1180 px сайдбар всегда свёрнут в полосу 52 px.

## Компоненты
- Тулбар: проект + чип гайда по центру; справа статус агента («Агент свободен» / «Ждёт агента» / «Агент работает» / «Ждёт ответа в чате» / «Агент не отвечает») и «Экспорт».
- Миниатюры: iframe со scale, номер, глаз (скрыть/показать), бейдж черновиков, перетаскивание для порядка.
- Поповер выделения: тёмная кнопка «Комментировать» → форма с цитатой; Cmd+Enter — добавить.
- Карточки черновиков и заданий; в задании — результат каждой правки, команда правок установленного агента (`/presentations правки` или `$slides правки`) с копированием.
- Сайдбар: кнопка «Скрыть панель» внизу; свёрнутый — полоса 52 px с той же кнопкой; анимация grid-template-columns (--spring), состояние `pd:side-collapsed`.
- В задании у последней правки каждого слайда — «Откатить слайд» / «Вернуть правки слайда» и метка «Откатено» (тексты правок зачёркнуты).
- Сайдбар: при наведении на проект или гайд справа появляется корзина (`.side-del`) → окно подтверждения (`#deleteScrim`, красная иконка, фокус на «Отмена», для гайда — сколько проектов его используют) → папка в Корзину macOS. «Новый проект» и «Новый гайдлайн» открывают sheet-формы; у заявок в работе — бейдж состояния; клик по гайду — его эталоны только для просмотра.
- Формы (`.form-sheet`): поля на `--fill-2`, свои выпадающие списки (`.select`, пункты с подписью, клавиатура), мини-сегменты (`.seg-mini`), тумблеры iOS (`.switch`, вкл. — зелёный), чипы пресетов, список файлов «имя · папка» с крестиком.
- Режим «только просмотр» (`.app.readonly`: гайд или проект в работе агента): вместо инспектора — карточка статуса с этапами, вопросом агента, прогрессом, командой (кнопка-иконка копирования) и «Отменить».
- Экспорт — sheet сверху: PDF / JPEG / PPTX (неактивен), строка «Сохранить в … · Изменить…», последние PDF/JPEG с «Показать в Finder», прогресс.
- Тост внизу по центру.

## Поведение
- Опрос API 1,5 с (0,6 с во время экспорта); превью перезагружается при смене mtime, но не во время ввода/открытого поповера.
- В localStorage: черновики (`pd:drafts:<проект>`) и текущий слайд (`pd:current:<проект>`).
- Стрелки ↑/↓ — переключение слайдов, Esc — закрыть выпадающий список, затем sheet или поповер.
