# Экспорт (`app/core/exporter.py`)

## Результат
| Формат | Куда | Как |
|---|---|---|
| PDF | `Экспорт/<Проект>/PDF/<Проект>.pdf` | `/print/{p}` → Chrome `--print-to-pdf`; страница 1920x1080 px (1440x810 pt) |
| JPEG | `Экспорт/<Проект>/JPEG/NN-<slide>.jpg` | Chrome `--screenshot --window-size=1920,1080 --virtual-time-budget=5000` → `sips` JPEG q92, 4 параллельно |
| PPTX | `Экспорт/<Проект>/PPTX/<Проект>.pptx` + `Шрифты/` | редактируемый, без pip → `docs/modules/pptx-converter.md` |

- Другая папка: «Изменить…» → `POST /api/pick {kind: folder}` → окно macOS (osascript `choose folder`); сервер хранит путь, браузер получает токен. Выбор действует на один экспорт. В чужой папке ничего не перезаписывается: `<Проект>.pdf` / `<Проект> — JPEG` / `<Проект> — PPTX` (pptx + «Шрифты» вместе), при совпадении — « 2», « 3»…
- Последний результат по каждому формату — `export-status.json.last.{pdf,jpeg,pptx}` (путь, время); в окне экспорта всегда есть строки с «Показать в Finder» (`/api/projects/{p}/reveal {format}`, путь берётся только из статуса).
- Только видимые слайды, в порядке `order`.
- JPEG 1x (1920x1080), PDF без пережатия картинок (~30 МБ на 29 слайдов демо) — решение автора.
- Замеры на демо (29 слайдов): PDF ~5 с, JPEG ~16 с, PPTX ~15 с.

## Надёжность
- Chrome с временным профилем (`pd-chrome-*`), удаляется после.
- **JPEG без `--virtual-time-budget` иногда снимался до загрузки шрифтов — текст слайда пропадал** (1 из 3 прогонов, исправлено 2026-10-13). PDF печать ждёт шрифты сама (4 прогона — байт в байт).
- Ждём файл со стабильным размером, а не выход процесса (Chrome с отдельным профилем может не завершаться). Таймаут: PDF 180 с, JPEG 45 с на слайд, чтение слайдов для PPTX 180 с → `killpg` (EPERM на группе Chrome ловится, тогда `proc.kill()`).
- stderr Chrome только в лог (в нём всегда есть безвредные ERROR).
- Результат пишется во временный файл/папку и подменяется атомарно; при ошибке временное удаляется, старый результат остаётся.
- PDF проверяется по сигнатуре `%PDF-`; JPEG — по количеству файлов.
- Один экспорт на проект одновременно (409).
- Статус: `Проекты/<p>/export-status.json` `{format, status, stage, progress, total, path, error, raster}` (`stage` и `raster` — у PPTX); при старте сервера `in_progress` → `failed` («прерван перезапуском»).

## Ошибки для пользователя
- Нет Chrome → «Не найден Google Chrome…».
- Нет видимых слайдов, таймаут, повреждённый файл — текстом в статусе.
