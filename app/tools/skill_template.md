# {{CMD}}

Слово после команды выбирает действие ниже. Без слова — «старт».

Приложение установлено в `{{APP}}`. Все команды ниже работают из любой папки, всегда с этим абсолютным путём.

Скрипты приложения всегда вызывай отдельной командой ровно так: `python3 "{{APP}}/app/tools/<скрипт>.py" …` — абсолютный путь в кавычках, без `cd`, без `/usr/bin/python3`, без цепочек через `&&`. Под эту форму настроены разрешения агента; в другой форме скрипт упрётся в песочницу (Keynote, Chrome и локальный сервер станут недоступны). Если в процедуре написано `python3 app/tools/…` или `agent.py …`, подставляй этот полный путь.

## Без аргументов или «старт»
1. Выполни `python3 "{{APP}}/app/tools/launch.py" start`.
2. Сообщи пользователю адрес из ответа: приложение открыто в браузере.
3. Если `ok: false`, покажи текст ошибки и последние строки `{{APP}}/.state/server.out`.

## «правки»
Обработай задания из приложения строго по `{{APP}}/.claude/commands/process-edits.md`. Прочитай этот файл и выполняй его шаги.

Пути к слайдам бери из ответа `claim`. Правила работы со слайдами описаны в `{{APP}}/CLAUDE.md`, раздел «Правки из приложения». Прочитай его перед первой правкой.

## «гайд»
Собери гайдлайн по заявке из приложения строго по `{{APP}}/.claude/commands/build-guide.md` (APP = `{{APP}}`). Прочитай файл целиком и выполняй шаги по порядку.

## «создать»
Создай презентацию по заявке из приложения строго по `{{APP}}/.claude/commands/create-presentation.md` (APP = `{{APP}}`). Прочитай файл целиком и выполняй шаги по порядку. Вопросы пользователю — строго по одному.

## «стоп»
`python3 "{{APP}}/app/tools/launch.py" stop`. Проекты и экспорт сохраняются.

## «статус»
Выполни `python3 "{{APP}}/app/tools/launch.py" status` и `python3 "{{APP}}/app/tools/agent.py" status`. Коротко скажи, запущено ли приложение и есть ли задания, ожидающие агента.
