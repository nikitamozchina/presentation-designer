# Дизайнер презентаций

Локальное приложение для презентаций по корпоративным гайдлайнам. ИИ-агент Claude Code собирает правила оформления (гайдлайн) из ваших материалов, создаёт по ним презентацию после короткого интервью и вносит правки по вашим комментариям. В браузере вы смотрите слайды, комментируете, скрываете лишнее и выгружаете PDF, JPEG или редактируемый PPTX. Всё работает на вашем компьютере, файлы никуда не загружаются.

Только macOS. Гайдлайнов в репозитории нет: собери свой из шрифтов, шаблонов и брендбуков (раздел «Новый гайдлайн») или поставь готовый пакет, если он у тебя есть.

## Установка

Дайте вашему Claude Code ссылку на этот репозиторий и попросите: «установи по INSTALL.md». Если есть пакет гайдлайнов, подготовьте путь к нему: агент спросит.

Что понадобится на компьютере:
- Python 3.9+ (macOS сама предложит поставить Command Line Tools);
- Google Chrome — для экспорта и самопроверки слайдов;
- **Keynote** — обязательно, бесплатно в App Store; через него агент читает презентации pptx и key;
- Claude Code с вашей подпиской.

Других программ и пакетов не нужно.

При первом разборе презентации macOS спросит, можно ли управлять Keynote. Нажмите «Разрешить».

## Команды

В Claude Code, из любой папки:

| Команда | Что делает |
|---|---|
| `/presentations` | Открыть приложение |
| `/presentations создать` | Агент берёт новый проект из приложения: интервью, структура, слайды |
| `/presentations гайд` | Агент собирает гайдлайн из папки, которую вы указали в приложении |
| `/presentations правки` | Внести правки, сохранённые в приложении |
| `/presentations статус` | Запущено ли приложение, есть ли задания |
| `/presentations стоп` | Остановить приложение |

Без Claude Code приложение можно открыть двойным кликом по `start.command` в папке приложения.

Агент сам не стартует. После каждого действия в приложении оно подскажет, какую команду отправить, и даст кнопку «Копировать».

## Новый проект

1. **«Новый проект»** в боковой панели. Заполните поля:
   - задача: *Создать*, *Дополнить* или *Пересобрать*. Для двух последних укажите исходную презентацию: проект из приложения или файл;
   - гайдлайн;
   - тема;
   - длительность в минутах — ориентир «1 слайд ≈ 1 минута»;
   - автор для титула — можно сохранить пресетом;
   - файлы с фактурой: отчёты, таблицы, старые презентации.

   Оригиналы ваших файлов не меняются: в проект копируются их копии.
2. Отправьте в Claude Code `/presentations создать`.
3. Агент задаст несколько вопросов **по одному**: цель, аудитория, главная мысль… Если надоело, напишите «хватит», и он пойдёт дальше. Пока агент ждёт ответа, в приложении горит «Нужен ваш ответ».
4. Агент покажет структуру слайдов. Поправьте её или напишите «ок».
5. Слайды появляются в приложении по мере готовности. Если включена «Проверить слайды», агент сам находит вылезающий и мелкий текст, плохой контраст и пустые места и исправляет их.
6. Пока проект собирается, его можно только смотреть. Комментарии и экспорт откроются, когда статус станет «Готово».

Цифры агент берёт только из ваших файлов и ответов. Если данных не хватает, он поставит на слайде пометку `[нужны данные: …]` и скажет об этом в отчёте.

## Новый гайдлайн

1. **«Новый гайдлайн»**, затем название и папка с материалами: шрифты, шаблоны pptx/key, брендбуки PDF, иконки.
2. Тумблер «Сделать эталонные слайды» лучше оставить включённым: агент нарисует 10 образцов, включая графики и таблицу. По ним видно, правильно ли понят стиль, и новые презентации получаются точнее.
3. Отправьте `/presentations гайд`. Если чего-то не хватает (например, файлов шрифта), агент спросит в чате и предложит варианты.
4. Клик по гайдлайну в боковой панели показывает его эталоны.

## Правки

1. Выберите слайд слева. Комментарий ко всему слайду пишите в поле под превью. Чтобы прокомментировать фрагмент, выделите текст на слайде и нажмите «Комментировать».
2. Комментарии копятся во вкладке «Комментарии» и не теряются при перезагрузке. Нажмите «Отправить агенту», затем отправьте `/presentations правки`.
3. Во вкладке «Задания» видно, что сделано и где агенту нужен ваш ответ. Не понравилось — «Откатить слайд»: уберутся правки этого задания только на этом слайде. Передумали — «Вернуть правки слайда».
4. Скрыть слайд можно глазом на миниатюре. Файл слайда при этом не удаляется, слайд просто не попадёт в экспорт. Порядок меняется перетаскиванием.

## Удаление

Наведите на проект или гайдлайн в боковой панели и нажмите появившуюся корзину, затем подтвердите. Папка переедет в Корзину macOS, оттуда её можно вернуть, пока Корзина не очищена. Готовые файлы в `Экспорт/` не удаляются. Пока агент работает над проектом или гайдлайном, удалить его нельзя.

## Экспорт

Кнопка «Экспорт», затем PDF, JPEG или PPTX. По умолчанию файлы сохраняются в `Экспорт/<Проект>/`. Другую папку можно выбрать кнопкой «Изменить…»: выбор действует на один экспорт. Последние PDF и JPEG всегда видны в окне экспорта, рядом кнопка «Показать в Finder».

**PPTX** — редактируемая презентация для PowerPoint и Keynote: тексты и плашки можно править. Графики на SVG и скриншоты баннеров вставляются картинками — окно экспорта скажет, на каких слайдах. Рядом с файлом лежит папка «Шрифты»: на компьютере без шрифта гайда текст покажется другим шрифтом и может переноситься иначе — шрифт нужно установить.

## Если что-то пошло не так

| Что видно | Что делать |
|---|---|
| «Нет связи с приложением» | Сервер остановлен — `/presentations` |
| «Ждёт агента» | Отправьте команду из карточки справа (кнопка копирования) |
| «Нужен ваш ответ» | Ответьте агенту в чате Claude Code. Чат закрыт — отправьте команду снова, агент повторит вопрос |
| «Агент не отвечает» | Агент прервался. Отправьте ту же команду ещё раз — он продолжит с того же места |
| Агент пишет, что не может управлять Keynote | Системные настройки → Конфиденциальность → Автоматизация → разрешите для Terminal/Claude. Или `tccutil reset AppleEvents` и повторите |
| Экспорт: «Не найден Google Chrome» | Установите Chrome и повторите |
| Неудачная правка | «Откатить слайд» во вкладке «Задания» |
| «Конфликт» при откате | Этот фрагмент позже изменило другое задание — сначала откатите его |
| Передумали создавать | «Отменить» в карточке статуса справа |

Журнал сервера: `.state/server.log`.

## Остановка

`/presentations стоп` или двойной клик по `stop.command`. Проекты, комментарии и экспорт сохраняются.

## Где что лежит

```
Экспорт/      готовые PDF, JPEG и PPTX, по проектам
Проекты/      слайды, исходники и бриф, задания на правки, история
Гайдлайны/    правила оформления: стили, шрифты, иконки, эталоны
app/          код приложения
docs/         документация для разработки (начать с docs/INDEX.md)
```
