# Дизайнер презентаций

Приложение делает презентации по гайдлайну твоей компании. ИИ-агент Claude Code собирает правила оформления из твоих шрифтов, шаблонов и брендбуков. Потом он задаёт несколько вопросов, согласует структуру и рисует слайды. Ты смотришь их в браузере, оставляешь комментарии, а агент вносит правки. Готовую презентацию можно выгрузить в PDF, JPEG или редактируемый PPTX.

Всё работает на твоём компьютере: файлы никуда не загружаются.

## Что нужно

- Mac с macOS. На Windows и Linux приложение не работает.
- [Claude Code](https://code.claude.com/docs/en/setup) с подпиской Claude.
- **Keynote** — обязательно. Он бесплатный и ставится из App Store. Через него агент читает файлы pptx и key.
- **Google Chrome** — для экспорта и проверки слайдов. Без него приложение откроется, но выгрузить презентацию не получится.
- Python 3.9 или новее. Если его нет, macOS сама предложит поставить Command Line Tools — соглашайся.

Больше ничего ставить не нужно.

## Установка

1. Открой Claude Code и напиши:
   > Установи https://github.com/nikitamozchina/presentation-designer по INSTALL.md
2. Агент спросит, в какую папку поставить приложение. Не выбирай iCloud Drive, Dropbox и другие синхронизируемые папки: синхронизация ломает служебные файлы.
3. Если у тебя есть готовый пакет гайдлайнов, агент попросит путь к нему. Если пакета нет, просто скажи об этом: первый гайдлайн ты соберёшь сам.
4. macOS покажет окно «… хочет управлять Keynote». Нажми «Разрешить».
5. В конце откроется браузер с приложением. После установки перезапусти Claude Code, чтобы появилась команда `/presentations`.

## Как работать

Агент сам не запускается. Когда ты что-то создаёшь в приложении, справа появляется карточка с командой и кнопкой копирования. Вставь эту команду в Claude Code.

### 1. Собери гайдлайн

Пропусти этот шаг, если гайдлайн пришёл в пакете.

1. В боковой панели нажми **«Новый гайдлайн»**.
2. Введи название и выбери папку с материалами: шрифты, шаблоны pptx или key, брендбуки в PDF, иконки.
3. Оставь включённым **«Сделать эталонные слайды»**. Агент нарисует 10 образцов: титул, текст, цифры, графики, таблицу. По ним сразу видно, правильно ли он понял стиль.
4. Отправь в Claude Code `/presentations гайд`. Если чего-то не хватает, например файлов шрифта, агент спросит в чате.
5. Когда гайдлайн готов, кликни по нему в боковой панели, чтобы посмотреть эталоны.

### 2. Создай презентацию

1. В боковой панели нажми **«Новый проект»** и заполни форму:
   - **Задача:**
     - *Создать* — новая презентация с нуля;
     - *Дополнить* — добавить слайды в готовую;
     - *Пересобрать* — перенести старую презентацию в новый гайдлайн.
   - **Гайдлайн и тема.** Из темы и даты получится название проекта.
   - **Длительность** — по желанию. Ориентир: примерно 1 слайд на минуту.
   - **Автор на титуле** — по желанию. Имя и должность можно сохранить как пресет.
   - **Материалы:** отчёты, таблицы, старые презентации, картинки. В проект уходят копии, оригиналы не меняются.
2. Отправь в Claude Code `/presentations создать`.
3. Агент задаст вопросы по одному: цель, аудитория, главная мысль. Если вопросы надоели, напиши «хватит».
4. Агент покажет структуру. Поправь её или напиши «ок».
5. Слайды появляются в приложении по мере готовности. Если включена **«Проверить слайды»**, агент сам найдёт и исправит вылезающий текст, мелкий шрифт и плохой контраст.

Цифры агент берёт только из твоих файлов и ответов. Если данных не хватит, он поставит на слайде пометку `[нужны данные: …]`.

### 3. Внеси правки

1. Выбери слайд слева. Комментарий ко всему слайду пиши в поле под слайдом. Чтобы прокомментировать кусок текста, выдели его на слайде и нажми **«Комментировать»**.
2. Когда комментарии готовы, нажми **«Отправить агенту»** и отправь в Claude Code `/presentations правки`.
3. Во вкладке **«Задания»** видно, что агент сделал, а где ему нужен твой ответ. Если правка не понравилась, нажми **«Откатить слайд»**: правки этого задания исчезнут только с этого слайда. Передумал — нажми **«Вернуть правки»**.
4. Глаз на миниатюре скрывает слайд: он останется в проекте, но не попадёт в экспорт. Порядок слайдов меняется перетаскиванием.

### 4. Выгрузи

Нажми **«Экспорт»** и выбери формат:
- **PDF** — один файл;
- **JPEG** — по картинке 1920×1080 на каждый слайд;
- **PPTX** — редактируемый файл для PowerPoint и Keynote. Графики и скриншоты баннеров вставляются картинками, окно экспорта скажет, на каких слайдах. Рядом с файлом лежит папка «Шрифты». Если отправляешь презентацию на другой компьютер, там нужно установить эти шрифты, иначе текст поедет.

По умолчанию файлы сохраняются в `Экспорт/<название проекта>/`. Другую папку выбирают кнопкой «Изменить…», и выбор действует на один экспорт.

### Удаление проекта или гайдлайна

Наведи курсор на проект или гайдлайн в боковой панели, нажми на корзину и подтверди. Папка переедет в Корзину macOS, и оттуда её можно вернуть. Файлы из `Экспорт/` не удаляются.

## Команды Claude Code

Команды работают из любой папки.

| Команда | Что делает |
|---|---|
| `/presentations` | Открыть приложение |
| `/presentations гайд` | Собрать гайдлайн |
| `/presentations создать` | Сделать новую презентацию |
| `/presentations правки` | Внести правки из комментариев |
| `/presentations статус` | Показать, запущено ли приложение и есть ли задания |
| `/presentations стоп` | Остановить приложение |

Без Claude Code приложение открывается двойным кликом по `start.command`, а закрывается через `stop.command`. Оба файла лежат в папке приложения. Проекты и комментарии при остановке сохраняются.

## Если что-то не так

| Что видишь | Что делать |
|---|---|
| «Нет связи с приложением» | Приложение остановлено. Отправь `/presentations` |
| «Ждёт агента» | Скопируй команду из карточки справа и отправь в Claude Code |
| «Нужен ответ в чате» | Ответь агенту в Claude Code. Если чат закрыт, отправь команду снова: агент повторит вопрос |
| «Агент не отвечает» | Агент прервался. Отправь ту же команду ещё раз, он продолжит с того же места |
| Агент пишет, что не может управлять Keynote | Системные настройки → Конфиденциальность и безопасность → Автоматизация → разреши для Терминала или Claude |
| «Нужен Google Chrome» при экспорте | Установи Chrome и повтори |
| Правка не понравилась | «Откатить слайд» во вкладке «Задания» |
| «Конфликт» при откате | Этот фрагмент позже поменяло другое задание. Сначала откати его |
| Передумал создавать проект | «Отменить» в карточке справа |

Если ничего не помогает, загляни в журнал `.state/server.log` в папке приложения.

## Обновление и удаление приложения

- **Обновить:** напиши Claude Code «Обнови presentation-designer: git pull и заново install.py». Проекты и гайдлайны при этом сохранятся.
- **Удалить:** напиши Claude Code «Удали presentation-designer: install.py --uninstall». Команда уберёт `/presentations` и разрешения агента. Если твои проекты больше не нужны, после этого удали саму папку приложения.

## Где что лежит

```
Экспорт/      готовые PDF, JPEG и PPTX по проектам
Проекты/      слайды, материалы, комментарии и история правок
Гайдлайны/    правила оформления: стили, шрифты, иконки, эталоны
app/          код приложения
docs/         документация для разработчиков (начать с docs/INDEX.md)
```
