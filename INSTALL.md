# Установка — инструкция для ИИ-агента (Claude Code)

Пользователь дал тебе ссылку на этот репозиторий и попросил установить «Дизайнер презентаций». Выполни шаги по порядку. Каждый шаг проверяй по его результату. Если шаг не удался, остановись и объясни пользователю, что случилось. Не обходи ошибки.

## 1. Требования
- Только macOS.
- `python3 --version` должен показать 3.9 или новее. Если macOS предлагает установить Command Line Tools, попроси пользователя согласиться и дождись окончания. Альтернатива — установщик с python.org.
- Google Chrome в `/Applications`. Без него приложение работает, но экспорт PDF/JPEG и самопроверка слайдов недоступны. Предупреди пользователя об этом.
- **Keynote** в `/Applications` (бесплатно, App Store) — обязателен: через него разбираются презентации pptx/key. Нет Keynote — попроси пользователя установить его и только потом продолжай.
- Во время установки macOS покажет окно «… хочет управлять Keynote». Предупреди пользователя заранее: нужно нажать «Разрешить». Если он отказал — `tccutil reset AppleEvents` и запусти установку снова.

## 2. Код
- Спроси пользователя, в какую папку поставить приложение, и клонируй репозиторий туда. Дальше эта папка — `<APP>`.
- Не ставь приложение в iCloud Drive, Dropbox и другие синхронизируемые папки: синхронизация ломает служебные файлы.

## 3. Пакет гайдлайнов
- Шрифты и корпоративные материалы в репозитории не хранятся. Спроси у пользователя путь к папке пакета: в ней лежат подпапки `Гайдлайны/` и, возможно, `Проекты/`.
- Пакета нет — это нормально: установи без `--pack`. Скажи пользователю, что первый гайдлайн он соберёт сам через «Новый гайдлайн» в приложении.

## 4. Установка
```bash
python3 "<APP>/app/tools/install.py" --pack "<путь к пакету>"
```
Установщик:
- проверяет Python, Chrome и Keynote (пробная конвертация; без Keynote останавливается);
- копирует пакет;
- создаёт глобальную команду `/presentations` (`~/.claude/skills/presentations/`);
- добавляет в `~/.claude/settings.json` разрешения только на папку приложения: чтение, правку `Проекты/` и `Гайдлайны/`, запуск своих скриптов из `app/tools/`. Перед этим делает бэкап.

Повторный запуск безопасен. Удаление: `install.py --uninstall`. Данные пользователя оно не трогает.

## 5. Проверка
- Выполни `python3 "<APP>/app/tools/launch.py" start`. Ответ должен содержать `"ok": true` и адрес, а в браузере должно открыться приложение.
- Скажи пользователю, что дальше всё запускается командой `/presentations` из любой папки. Если команда не появилась, нужно перезапустить Claude Code.

## Команды после установки
| Команда | Что делает |
|---|---|
| `/presentations` | Открыть приложение (запустит сервер, если нужно) |
| `/presentations создать` | Создать презентацию по заявке из приложения (интервью → структура → слайды) |
| `/presentations гайд` | Собрать гайдлайн из папки, указанной в приложении |
| `/presentations правки` | Внести правки, сохранённые в приложении |
| `/presentations статус` | Запущено ли приложение, есть ли задания |
| `/presentations стоп` | Остановить приложение |
