# Установка — инструкция для ИИ-агента (Claude Code или Codex)

Пользователь дал тебе ссылку на этот репозиторий и попросил установить «Дизайнер презентаций». Выполни шаги по порядку. Каждый шаг проверяй по его результату. Если шаг не удался, остановись и объясни пользователю, что случилось. Не обходи ошибки.

## 1. Требования
- Только macOS.
- `python3 --version` должен показать 3.9 или новее. Если macOS предлагает установить Command Line Tools, попроси пользователя согласиться и дождись окончания. Альтернатива — установщик с python.org.
- Google Chrome в `/Applications`. Без него приложение работает, но экспорт PDF/JPEG и самопроверка слайдов недоступны. Предупреди пользователя об этом.
- **Keynote** или **Keynote Creator Studio** (бесплатно, App Store; подойдёт любая версия) — обязателен: через него разбираются презентации pptx/key. Нет Keynote — попроси пользователя установить его и только потом продолжай.
- Во время установки macOS покажет окно «… хочет управлять Keynote». Предупреди пользователя заранее: нужно нажать «Разрешить». Если он отказал — `tccutil reset AppleEvents` и запусти установку снова.

## 2. Код
- Спроси пользователя, в какую папку поставить приложение, и клонируй репозиторий туда. Дальше эта папка — `<APP>`.
- Не ставь приложение в iCloud Drive, Dropbox и другие синхронизируемые папки: синхронизация ломает служебные файлы.

## 3. Пакет гайдлайнов
- Шрифты и корпоративные материалы в репозитории не хранятся. Спроси у пользователя путь к папке пакета: в ней лежат подпапки `Гайдлайны/` и, возможно, `Проекты/`.
- Пакета нет — это нормально: установи без `--pack`. Скажи пользователю, что первый гайдлайн он соберёт сам через «Новый гайдлайн» в приложении.

## 4. Установка
Определи, кто ты: **Claude Code** → `--agent claude`, **Codex** → `--agent codex`. Ставь только под себя.
```bash
python3 "<APP>/app/tools/install.py" --agent claude --pack "<путь к пакету>"
python3 "<APP>/app/tools/install.py" --agent codex --pack "<путь к пакету>"
```
Без пакета — без `--pack`.

**Если ты Codex:** `git clone` в папку пользователя и `install.py` запускай вне песочницы, с запросом подтверждения у пользователя. В песочнице установщик не сможет проверить Keynote и записать настройки в `~/.codex` и `~/.agents`. Предупреди пользователя, что подтверждение понадобится.

Установщик:
- проверяет Python, Chrome и Keynote (пробная конвертация; без Keynote останавливается);
- копирует пакет;
- Claude Code:
  - создаёт команду `/presentations` (`~/.claude/skills/presentations/`);
  - добавляет в `~/.claude/settings.json` разрешения только на папку приложения: чтение, правку `Проекты/` и `Гайдлайны/`, запуск своих скриптов из `app/tools/`;
- Codex:
  - создаёт команду `$slides` (`~/.agents/skills/slides/`);
  - создаёт правила `~/.codex/rules/presentation-designer.rules`, чтобы скрипты приложения работали вне песочницы без вопросов;
  - добавляет папку приложения в `sandbox_workspace_write.writable_roots` в `~/.codex/config.toml`;
- перед правкой настроек делает бэкап; что поставил, записывает в `<APP>/.state/install.json`.

Если установщик пишет, что не смог безопасно поправить `config.toml`, покажи пользователю строки, которые он предлагает добавить вручную.

Повторный запуск безопасен. Удаление: `install.py --uninstall`. Данные пользователя оно не трогает.

## 5. Проверка
- Claude Code: выполни `python3 "<APP>/app/tools/launch.py" start`. Ответ должен содержать `"ok": true` и адрес, а в браузере должно открыться приложение. Скажи пользователю, что дальше всё запускается командой `/presentations` из любой папки. Если команда не появилась, нужно перезапустить Claude Code.
- Codex: правила подхватываются только в новой сессии. Выполни `python3 "<APP>/app/tools/launch.py" start` вне песочницы (с подтверждением) и скажи пользователю открыть новую сессию Codex: дальше всё запускается командой `$slides` из любой папки.

## Команды после установки
В Claude Code — `/presentations …`, в Codex — `$slides …`. Слово после команды выбирает действие.

| Команда | Что делает |
|---|---|
| `/presentations` · `$slides` | Открыть приложение (запустит сервер, если нужно) |
| `… создать` | Создать презентацию по заявке из приложения (интервью → структура → слайды) |
| `… гайд` | Собрать гайдлайн из папки, указанной в приложении |
| `… правки` | Внести правки, сохранённые в приложении |
| `… статус` | Запущено ли приложение, есть ли задания |
| `… стоп` | Остановить приложение |
